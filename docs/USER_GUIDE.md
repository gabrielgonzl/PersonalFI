# 📘 Growing - User Guide

Complete guide to using the Growing personal investment tracker.

## 🎯 Overview

Growing helps you track and manage your investment portfolio across multiple asset types including stocks, cryptocurrencies, ETFs, and more.

## 🏠 Dashboard

The dashboard provides an overview of your entire investment portfolio.

### Key Metrics

- **Total Portfolio Value**: Sum of all your assets' current value
- **Total Invested**: Amount you've invested across all assets
- **Total Profit/Loss**: Overall return on your investments
- **Return Percentage**: Portfolio performance as a percentage

### Quick Actions

- View recent transactions
- See top performing assets
- Access portfolio analytics
- Quick navigation to assets and portfolios

## 💼 Managing Assets

### Creating an Asset

1. Navigate to **Assets** from the sidebar
2. Click **Create Asset** button
3. Fill in the details:
   - **Name**: Asset name (e.g., "Bitcoin", "Apple Stock")
   - **Symbol**: Trading symbol (e.g., "BTC", "AAPL")
   - **Type**: Asset category (crypto, stock, ETF, etc.)
   - **Portfolio**: Assign to a portfolio (optional)
   - **Current Price**: Latest market price
   - **Description**: Additional notes

4. Click **Create Asset**

### Viewing Asset Details

Click on any asset to view:
- Current value and performance
- Purchase history
- Price changes
- Performance charts
- Allocation in portfolio

### Editing an Asset

1. Open asset details
2. Click **Edit** button
3. Update information
4. Click **Save Changes**

### Deleting an Asset

1. Open asset details
2. Click **Delete** button
3. Confirm deletion

⚠️ **Warning**: Deleting an asset also removes all associated transactions.

## 📊 Managing Portfolios

Portfolios help you organize assets into groups (e.g., "Long-term", "Trading", "Retirement").

### Creating a Portfolio

1. Navigate to **Portfolios**
2. Click **Create Portfolio**
3. Enter details:
   - **Name**: Portfolio name
   - **Description**: Purpose or strategy
   - **Currency**: Base currency
   - **Initial Cash**: Starting cash balance

4. Click **Create Portfolio**

### Adding Assets to Portfolio

When creating/editing an asset, select the target portfolio from the dropdown.

### Portfolio Operations

**Add Cash**
1. Open portfolio details
2. Click **Add Cash**
3. Enter amount and date
4. Click **Confirm**

**Distribute Cash**
1. Open portfolio details
2. Click **Distribute Cash**
3. Allocate amounts to assets
4. Click **Distribute**

**Rebalance**
1. Open portfolio details
2. Click **Rebalance**
3. Set target allocation percentages
4. Review suggested trades
5. Click **Execute Rebalance**

## 💰 Recording Transactions

### Buy Transaction

1. Navigate to asset details or click **New Transaction**
2. Select transaction type: **Buy**
3. Fill in:
   - **Quantity**: Number of units
   - **Price**: Purchase price per unit
   - **Date**: Transaction date
   - **Fees**: Trading fees (optional)
   - **Notes**: Additional information

4. Click **Record Transaction**

### Sell Transaction

1. Select transaction type: **Sell**
2. Enter quantity to sell
3. Enter selling price
4. Add fees and notes
5. Click **Record Transaction**

### Transfer Transactions

**Transfer In**: Moving assets into your tracked portfolio
**Transfer Out**: Moving assets out of your tracked portfolio

## ❓ Frequently Asked Questions

**Q: How often should I update prices?**
A: Depends on your needs. Daily for active traders, weekly/monthly for long-term investors.

**Q: Can I track multiple currencies?**
A: Yes, each portfolio can have its own base currency.

**Q: What happens when I delete a portfolio?**
A: Assets in that portfolio become unassigned but aren't deleted.

**Q: Can I undo a transaction?**
A: Yes, find the transaction and click delete. Edit if you made a mistake.

**Q: How is profit/loss calculated?**
A: (Current Value - Total Invested) / Total Invested × 100

**Q: Can I import my existing data?**
A: Yes, use the CSV import feature in Settings.

**Q: Is my data secure?**
A: Data is stored locally or in your configured database. Use secure hosting for production.
